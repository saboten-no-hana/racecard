# 出資馬出走カードメーカー

一口馬主クラブの出資会員向けに、今週末に出走する出資馬を1枚の画像にまとめて、X（旧Twitter）に投稿できる形で書き出すツールです。

**https://saboten-no-hana.github.io/racecard/** （無料・登録不要）

- 複数クラブの出資馬を1枚に混在して並べられます（一口クラブ24クラブに対応。一覧と勝負服は `clubs.js`）
- 勝負服・競馬場とレース番号・レース名（重賞・リステッド・OP・条件特別は格つき）・発走時刻・コース・騎手を表示します
- 木曜の出走確定（枠順未定）の時点でも、金曜以降の枠順確定後（枠色つき馬番）でも使えます
- 日付ごとに 関東主場 → 関西主場 → 第3場 の順、その中はレース番号順に並べます（発走時刻順・入力順も選べます）
- 口取りの 当選／抽選待ち／落選 を表示できます
- 出走取消・競走除外になった馬は「出走取消」「競走除外」と表示されます（そのまま載せるか、削除するかを選べます）
- 背景は 芝・ダート・ナイター・白・G1・春・夏・秋・冬 と、色や画像を指定できるカスタム
- サイズは 縦長（幅1080、頭数に合わせて縦に伸びる）・正方形（1200×1200）・横長（1600×900から、16:9に近い形のまま広がる）
- 「画像を保存」「画像をコピー」「Xに投稿」で書き出せます
- 画像の右下に小さく「Powered by 出資馬出走カードメーカー」とURLが入ります（設定で外せます）
- 入力内容はブラウザ内（localStorage）にだけ保存され、どこにも送信されません

## 使い方

1. 「今週の出走馬から選ぶ」で、クラブや馬名（ひらがな・カタカナの一部でも可）で探して「追加」します。全項目が自動で入ります
2. ☆を押して★（出資馬）にしておくと、次に出走する週に「★の出資馬が今週N頭出走します［まとめて追加］」と出ます
3. 一覧にない馬（地方・海外遠征、個人馬主など）は「＋ 馬を追加」で手入力します。一覧にないクラブや個人馬主は「その他」を選び、「勝負服を設定」で勝負服を入れます
4. 口取り・写真・タイトル・デザイン・サイズを整えて、「画像を保存」または「Xに投稿」

- 追加した馬は、ページを開くたびに最新の出馬表で更新されます（枠・馬番・騎手・発走時刻・取消など）
- 出資馬の名前をまとめて★にするには「馬名をまとめて★を付ける」に馬名を書くか、出資馬の一覧が載ったページの文字を貼り付けます（カタカナの馬名を拾い出します。外部サイトへのアクセスはしません）。今週の出馬表にいない馬は「出走待ち」として名前で覚えておき、出走する週に自動で★に変わります
- ★は端末ごとに保存されます。別の端末へは「★を他の端末に引き継ぐ」のコードかリンクで移せます
- レースが終わった週の馬は「先週までの馬が残っています［消す］」で片付けられます

## 今週の出走馬の自動取得

`.github/workflows/fetch-races.yml` が JRA ホームページの出馬表を読み、一口クラブ名義の出走馬だけを `data/races.json` に保存します。

| 時刻（日本時間） | 内容 |
|---|---|
| 毎日 16:05〜 | 新しい開催日の出走確定（馬番なし）を確認。木曜は 18:30 まで5分おきに待ち、揃うまで取り直す |
| 木曜 19:05 | 安全網として1回取得（有馬記念の週の枠順抽選もここで拾う） |
| 毎日 10:05〜12:00 | 翌日の枠・馬番を確認して取得 |

- JRA の発表（木曜16時すぎ・レース前日10時すぎ）から20〜30分ほどでページに反映されます
- 個人馬主の名前は保存せず、馬ごとに「どのクラブの馬か」だけを `data/cache.json` に記録して再利用します
- 出馬表全体は公開せず、一口クラブ名義の馬だけを載せます
- 取得が止まった時（出馬表のページ形式が変わった、木曜に週末の出馬表を取れなかった ※年末年始を除く）は Actions が失敗になり、GitHub からメールが届きます

### 手動で取得する

GitHub のリポジトリで **Actions → 出馬表の取得 → Run workflow**（ブランチは main）を押すと、その場で1回取得します。変更があれば `data/` がコミットされ、数分でページに反映されます。

## 開発メモ

- 画面と画像の描画はすべて `index.html`（外部ライブラリなし）。ローカルでは `python3 -m http.server` で開けます
- クラブを追加する時は `clubs.js` にエントリを足し、勝負服画像のファイル名を `silks/sources.txt` に書いて push すると、`.github/workflows/fetch-silks.yml` が取得します

## 素材とライセンス

- 勝負服の画像は Wikipedia の各クラブ法人の記事に掲載されている Wikimedia Commons の画像（CC0）を `silks/` に保存して使っています。手描きの勝負服の形は、Commons の勝負服の標示の見本（CC0、`silks/examples/`）によります
- 写真は自分で撮影したものを使ってください。クラブ提供写真の転載は各クラブの規約を確認してください
- `og.png` は架空の馬名で作ったサンプル画像です
