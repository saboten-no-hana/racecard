# 愛馬出走カードメーカー

一口馬主クラブの出資会員向けに、今週末に出走する出資馬を1枚の画像にまとめて、X（旧Twitter）に投稿できる形で書き出すツールです。

- 複数クラブの出資馬を1枚に混在して並べられます
- クラブを選ぶと勝負服が自動で入ります（クラブの一覧と勝負服は `clubs.js` で管理）
- 木曜の出走確定時点（枠順未定）は競馬場とレース番号、金曜に枠・馬番を入れると枠色つきの馬番を表示します
- 口取りの当選／抽選待ち／落選を表示できます
- デザイン4種（芝・ダート・ナイター・白）、サイズ3種（4:5・1:1・16:9）
- 入力内容はブラウザ内にのみ保存され、どこにも送信されません

## 使い方

1. 「＋ 馬を追加」で出走馬を入力します
2. 一覧にないクラブや個人馬主は「その他」を選び、「勝負服を設定」で勝負服を入れます
3. 「画像を保存」でPNGを保存し、Xに投稿します

## 注意

- 勝負服は各クラブ法人の登録表記（Wikipedia掲載のもの）をもとに描いています。ウイン・YGG・グリーンファーム・ワラウカド・京都サラブレッドクラブは未登録です。

- 写真は自分で撮影したものを使ってください。クラブ提供写真の転載は各クラブの規約を確認してください。
