# 愛馬出走カードメーカー

一口馬主クラブの出資会員向けに、今週末に出走する出資馬を1枚の画像にまとめて、X（旧Twitter）に投稿できる形で書き出すツールです。

- 複数クラブの出資馬を1枚に混在して並べられます
- クラブを選ぶと勝負服が自動で入ります（クラブの一覧と勝負服は `clubs.js` で管理）
- 競馬場とレース番号を表示し、金曜に枠・馬番を入れるとその横に枠色つきの馬番も並びます（木曜の出走確定時点でも金曜の枠順確定後でも使えます）
- 日付ごとに競馬場の小見出しを付け、関東主場 → 関西主場 → 第3場の順、その中はレース番号順に並べます（発走時刻順・入力順も選べます）
- 口取りの当選／抽選待ち／落選を表示できます
- デザイン4種（芝・ダート・ナイター・白）、サイズ3種（4:5・1:1・16:9）
- 入力内容はブラウザ内にのみ保存され、どこにも送信されません

## 使い方

1. 「＋ 馬を追加」で出走馬を入力します
2. 一覧にないクラブや個人馬主は「その他」を選び、「勝負服を設定」で勝負服を入れます
3. 「画像を保存」でPNGを保存し、Xに投稿します

## 注意

- 勝負服の画像は Wikipedia の各クラブ法人の記事に掲載されている Wikimedia Commons の画像（CC0）を `silks/` に保存して使っています。取得は GitHub Actions（`.github/workflows/fetch-silks.yml`）で行い、`silks/sources.txt` にファイル名を足すと追加取得されます。

- 写真は自分で撮影したものを使ってください。クラブ提供写真の転載は各クラブの規約を確認してください。

## フォント

画像の文字には [IPAexゴシック](https://moji.or.jp/ipafont/)（Version 004.01）を使っています。
IPAフォントライセンスv1.0 に従い、フォントファイルは改変せずに `fonts/ipaexg.ttf` として同梱しています。
ライセンス文書は `fonts/IPA_Font_License_Agreement_v1.0.txt` を参照してください。
